Какие данные хранит приложение

FinSprint хранит на вашем устройстве данные, которые вы вводите в приложение: плановые доходы и траты, даты, настройки, отметки исполнения плана и выбранные параметры оформления. Эти данные нужны для работы приложения и его виджетов.

Сбор и передача данных

FinSprint не требует учётную запись, не подключается к банковским счетам и не отправляет введённый вами план разработчику или на серверы FinSprint. В приложении нет рекламы, аналитики, отслеживания между приложениями или сторонних SDK для сбора пользовательских данных.

Уведомления и резервные копии

Если вы разрешите уведомления, приложение создаёт напоминания средствами iOS на вашем устройстве. Push-уведомления через сервер не используются.

Если вы вручную экспортируете или импортируете резервную копию, выбранный вами файл обрабатывается через системный интерфейс iOS «Файлы». Место, куда вы сохраните файл, например облачное хранилище, регулируется условиями соответствующего провайдера.

Срок хранения и удаление

Данные FinSprint находятся в хранилище приложения на устройстве. Вы можете удалить их средствами приложения или iOS, удалив приложение вместе с его данными. Экспортированные вами файлы резервных копий нужно удалить отдельно в том месте, куда вы их сохранили.

Сайт поддержки

Эта информационная страница размещается на GitHub Pages. При открытии страницы GitHub может обрабатывать технические журналы, включая IP-адрес, в целях безопасности сервиса. Это относится к посещению сайта и не означает, что приложение FinSprint собирает эти данные. Подробнее — в политике конфиденциальности GitHub.
